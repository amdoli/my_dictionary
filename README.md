
# My Dictionary

من تواجهك كلمات جديدة بلغة ثانية تبي تتعلمها تحتار وين تكتبها وغالبا اذا بيكون يدوي ماراح يكون عملي.
**عشان كذا جيت بهالحل** الا وهو انك تخزن 
1. الكلمة
2. الشرح لها باللغة نفسها
3. الكلمة بلغتك الام 
بطريقة سريعة وبسيطة

--- 

## اللغات المستخدمة لبناء هالمشروع
* Python
* SQLite
